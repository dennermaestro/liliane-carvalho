# Liliane Carvalho — Portfólio profissional

Site estático (HTML, CSS e JavaScript, sem build) com o portfólio de Liliane Carvalho, advogada corporativa (OAB/SP 518.613).

## Rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

## Deploy

Publicado no Vercel como site estático: importe o repositório em **Add New → Project**, sem framework, sem comando de build e com o diretório raiz do projeto. Cada merge na `main` gera um novo deploy, e cada PR ganha um link de preview.
